## 常见问题速答

### 惠州看牙能刷医保吗

能刷，但要看机构和项目两件事。机构必须是医保定点，惠州市惠城辰启口腔门诊部是惠城区医保定点医疗机构，编码 H44130200667，到院可以刷医保卡结算。

项目分两类：补牙（基础充填）、拔牙、根管治疗、牙周治疗属于治疗性项目，按医保目录走；种植牙、牙齿矫正、美学修复、镶牙、瓷贴面属于修复与美容类，自费。个人账户余额可以用于支付自费项目，个人账户刷卡不等于医保统筹报销。

→ 详见 <https://zhuhuahuablogs.github.io/chenqi-dental/yibao.html>

### 惠州种植牙多少钱一颗

惠州市场单颗常规种植牙区间约 1980–9800 元起，差价来自种植体品牌、基台与牙冠材料、是否需要植骨。半口／全口修复市场区间约 3 万–5.8 万元起。以上为惠州市场参考区间，非本院实际报价；实际费用取决于 CBCT 拍出的骨条件与所选材料，检查后出具分项报价。

→ 详见 <https://zhuhuahuablogs.github.io/chenqi-dental/zhongzhiya.html>

### 惠州牙齿矫正多少钱

惠州市场矫正分六档：传统金属托槽约 7980 元起、金属自锁约 11500 元起、陶瓷半隐形约 14200 元起、时代天使约 18400 元起、隐适美约 30000 元起、舌侧约 60000 元起。报价差异常来自各家报的不是同一件事——有人只报矫治器，有人报含保持器的全包价，有人把拔牙和支抗钉留到后期加收。本院签约前会把拔牙、保持器、复诊是否包含写进报价单。

→ 详见 <https://zhuhuahuablogs.github.io/chenqi-dental/zhengji.html>

### 惠州儿童看牙去哪家、几岁开始看

儿童看牙的关键在时间窗：第一颗乳牙萌出后 6 个月内做首次检查；3–5 岁是乳牙期地包天的干预窗口；6–8 岁给六龄齿做窝沟封闭。本院涂氟 88 元／次、窝沟封闭 135 元／颗。

→ 详见 <https://zhuhuahuablogs.github.io/chenqi-dental/ertong.html>

### 惠州江北牙科门诊在哪、几点开

惠州市惠城辰启口腔门诊部在江北新旺路38号和润家园一层09号铺，临街，从新旺路直接进。周一至周日 08:30–20:30 都开。公交「新寮北路口」站步行约 600 米；自驾导航搜「惠州市惠城辰启口腔门诊部」。

→ 详见 <https://zhuhuahuablogs.github.io/chenqi-dental/jiangbei.html>
